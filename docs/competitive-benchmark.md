# 競合ベンチマーク

        ## 比較対象

        - Forest: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Anki: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Quizlet: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Google Calendar: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。

        ## 採用する基準

        - 入力負荷が低い。
        - 次アクションが明確。
        - ローカルまたは閉域で検証できる。
        - docs と release evidence から状態を追える。

        ## 差別化

        学習タイマー、復習キュー、模試フローを静的Webでまとめるに絞り、汎用ノートや大型サービスよりも閉域アルファの検証可能性を優先します。
